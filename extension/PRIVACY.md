# Privacy policy: Run with Vedocker

_Last updated: October 3, 2026_

Run with Vedocker does not collect, transmit, sell or share any personal data.

**What it stores.** One setting: the dashboard URL you enter on the options page (default `http://localhost:5173`). It's saved with the browser's `storage.sync` API, so it stays in your browser and, if you've turned on browser sync, syncs to your other devices through your browser vendor. The extension never sends it anywhere else.

**What it reads.** On `github.com` pages, the extension reads the page address and looks for GitHub's Code button so it can add a link next to it. Nothing it reads is stored or sent anywhere.

**Network requests.** None. The extension has no background script and makes no requests. When you click **Run with Vedocker**, your browser opens your own dashboard URL in a new tab, just like clicking any link.

**Analytics and tracking.** None.

**Permissions.**
- Access to `github.com`: to add the button to repo pages.
- `storage`: to remember your dashboard URL.

**Contact.** Questions or concerns: open an issue at https://github.com/Vedthakar/Vedocker/issues.
